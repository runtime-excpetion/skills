# 周报总结

把本周的飞书日历日程整理成一份**周报**：按时序列出每条日程，按类型打标签，并用「标题 + 描述」总结每条内容。

## 步骤

### 1. 确定时间范围

默认取本周（周一 00:00 至周日 23:59）。若用户在输入中指定了时间（如「上周」「7 月」），以用户指定为准。

**完成条件**：已明确起止时间，并将它作为下一步拉取日程的区间。

### 2. 拉取飞书日历日程

调用lark 相关 skills，拉取该时间区间内主日历的全部日程，取每条的「时间、标题、描述」。

如果 lark 相关 skills 不可用则使用接口方式拉取（鉴权、端点、参数、分页）见 `reference/feishu-calendar-api.md`。若飞书 API 凭证不可用，停止并向用户说明需先配置凭证。

**完成条件**：区间内全部日程的时间、标题、描述均已取到，无遗漏。

### 3. 按时序排列

按日程开始时间升序排列。

**完成条件**：列表自上而下时间严格递增。

### 4. 逐条归类与总结

对每条日程，先按下方【分类规则】判定类型并打标签，再用「标题 + 描述」总结成一行内容。

**完成条件**：每条日程都已完成标签判定（打或不打）与内容总结。

### 5. 输出周报

按时间顺序输出有序列表，每行格式：`【标签】 内容总结`；无标签的日程直接输出内容总结。

**完成条件**：本周所有日程均已列入、按序排列、标签与内容齐备。

## 分类规则

按日程的标题与描述判定类型，命中则在该行前加对应标签；三类均不命中的日程**不打标签**，正常列出。

- **【需求开发】**：涉及需求设计、开发实现、功能联调、提测、代码评审等开发类工作。
- **【运维处理】**：涉及问题排查、故障处置、线上问题处理等。此类必须包含「问题原因」与「解决方案」两项，从标题与描述中提取；提取不到的项填 `【未提供原因与解决方案】`。
- **【资料整理】**：涉及资料整理、文档编写、信息汇总、材料提供等。
