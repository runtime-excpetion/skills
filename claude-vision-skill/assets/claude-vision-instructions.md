## 图片识别

当前运行时通过 `scripts/vision.js` 使用外部视觉模型。

当用户提供本地图片、附件图片路径或 `Saved attachments:` 图片列表时：

1. 为每张图片使用绝对路径运行：

   ```bash
   node scripts/vision.js "<图片绝对路径>" "请用中文详细描述并分析这张图片"
   ```

2. 等待所有图片处理完成，再结合全部文字结果回复。
3. 将失败项与对应图片路径配对，报告错误类别和可执行的下一步。
4. 让 API 凭据保留在环境变量中；输出只包含配置状态，不包含变量值或请求头。

分析网络图片时使用：

```bash
node scripts/vision.js --url "<HTTPS 图片 URL>" "请用中文详细描述并分析这张图片"
```
